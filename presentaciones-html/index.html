Unidad III Clases prácticas y trabajo sobre el proyecto

Actividades prácticas 3 actividades

  1. Proyecto: Explicación - Traer consultas

    Actividad: explicar el proyecto y preparar consultas sobre sus requerimientos y las decisiones que necesiten validación.

  2. Documento ERS

    Actividad: trabajar con el Documento de Especificación de Requisitos de Software como insumo para el desarrollo del proyecto.

  3. C · Consultas - Proyecto / Tope de formación de Equipos

    Actividad: resolver consultas sobre el proyecto y establecer el tope para la formación de equipos.
